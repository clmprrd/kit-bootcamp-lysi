Les connecteurs dans un skill

Un skill peut aller chercher les données là où elles sont : un dossier SharePoint client, une pièce jointe Outlook, un fichier OneDrive. Il faut que le connecteur Microsoft 365 soit activé pour votre compte (voir jeudi, séquence 1). Claude demande confirmation avant toute écriture ou envoi.

10h00 - 13h00Séquence 7

Atelier : un skill sur une étape du bilan carbone

Ce que vous faitesPar groupes de 2 ou 3, vous choisissez une étape de votre méthode de bilan carbone, vous écrivez le skill qui l'automatise, et vous le faites tourner sur un vrai cas. Le groupe choisit son étape.
Durée3 h
FormatGroupes de 2 ou 3
Livrable1 skill qui tourne, présenté à 14h

Consignes, à suivre dans l'ordre

  1. 10h00, 5 min. Formez les groupes : mélangez les profils (associés, consultants, stagiaire).
  2. 10h05, 30 min. Cartographiez la méthode avec le prompt 1. Choisissez une étape : répétitive, bien documentée, dont on sait vérifier le résultat.
  3. 10h35, 10 min. Préparez un cas de test : les données d'un bilan déjà réalisé, dont vous connaissez le bon résultat.
  4. 10h45, 60 min. Écrivez le skill avec le prompt 2 et le modèle. Importez-le (Personnaliser › Skills).
  5. 11h45, 30 min. Faites-le tourner sur le cas de test. Comparez au résultat connu. Chaque écart devient une règle ou un contrôle dans le skill.
  6. 12h15, 30 min. Deuxième passage sur un autre cas. Notez ce qui reste à vérifier à la main.
  7. 12h45, 15 min. Préparez la démo de 14h : une entrée prête, le résultat attendu, les limites.

Prompt 1 · Cartographier la méthode

Voici notre méthode de bilan carbone, étape par étape : [décrire ou joindre]. Pour chaque étape, indique : - les données d'entrée ; - le traitement réalisé ; - le livrable produit ; - le temps passé estimé ; - le risque d'erreur si on l'automatise (faible, moyen, élevé). Recommande l'étape la plus rentable à automatiser en premier, et explique pourquoi.

Étapes souvent retenues

Normaliser les données reçues

Classer les données brutes du client par poste d'émission, convertir les unités, lister les manques.

Contrôler les facteurs d'émission

Relire un calcul et signaler chaque facteur sans source, périmé ou incohérent.

Demander les données manquantes

Rédiger la demande au client, poste par poste, avec le format attendu.

Synthétiser un poste

Produire la synthèse d'un poste d'émission pour le rapport ou les slides du client.

Prompt 2 · Écrire le skill

Aide-moi à créer un skill Claude pour cette étape de notre bilan carbone : [étape choisie]. Voici ce que nous recevons en entrée : [format, exemple anonymisé]. Voici ce que nous voulons en sortie : [livrable, format exact]. Voici les règles métier à respecter : [règles]. Pose-moi une par une les questions qui manquent, puis rédige le skill complet selon le modèle ci-dessous et prépare le dossier à importer.

Modèle de skill

--- name: [nom-court-de-l-etape] description: [Quand l'utiliser, avec les mots du consultant] --- # [Étape du bilan carbone] ## Entrées - [fichiers ou données attendus, format] ## Étapes 1. [étape] 2. [étape] 3. [étape] ## Sortie - [livrable, format exact] ## Règles - Ne jamais inventer un facteur d'émission : le signaler s'il manque. - Citer la source de chaque facteur utilisé. - [règle métier Lysi] ## Contrôles avant de rendre - [ex. unités cohérentes, total égal à la somme des postes] ## Exemple - Entrée : [cas réel anonymisé] - Sortie attendue : [résultat connu]
Piège : viser toute la méthode d'un coup. Un skill qui fait bien une étape vaut mieux qu'un skill qui fait mal cinq étapes.
Réussi si le skill tourne en direct sur un cas dont vous connaissez le résultat, et vous savez dire ce qu'il ne faut jamais lui confier sans vérification.
14h00 - 16h00Séquence 8

Atelier : tests croisés et itération collective

Ce que vous faitesD'abord, chaque groupe fait tourner le skill d'un autre groupe sur son propre cas. Ensuite, toute l'équipe construit ensemble un outil interne pour Lysi, avec des rôles et une contrainte.

Partie 1 · Tests croisés (14h00 - 15h00)

  1. 5 min par groupe. Le groupe montre son skill : l'étape choisie, la démo en direct, ses limites.
  2. 5 min. Le groupe suivant fait tourner ce skill sur son cas, sans aide.
  3. 3 min. Le groupe testeur répond à voix haute aux 3 questions ci-dessous.
  4. 2 min. Clément donne une amélioration concrète. Le groupe auteur la note.
Question du groupe testeurCe qu'on corrige si non
Le skill s'est-il déclenché sans être nommé ?La description
Le résultat est-il juste sur notre cas ?Une règle ou un contrôle
Qu'a-t-il fallu reprendre à la main ?Une étape à ajouter, ou une limite à écrire
